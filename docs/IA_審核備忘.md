## 一、阻斷級：同「唔收集查詢」底線直接衝突

### 涉及功能
- 實時熱門瀏覽榜（今日點擊 TOP30、近 7 日 TOP50）
- IP 人氣榜（**按查詢量**統計）
- 最近搜尋關鍵詞（自動保存）

### 問題
「今日點擊 TOP30」「按查詢量排名」呢兩個功能，本質上需要 **per-query 或 per-click 日誌**。
但已鎖定嘅私隱設計係：`page_view_daily` 只有 `(day, views)` 兩欄，冇 item、冇 query、冇 IP、冇 session。
**兩者只能活一個。**

### 三個可行方案（要你揀）

| 方案 | 做法 | 私隱 | 可行性 | 代價 |
|---|---|---|---|---|
| **A（推薦）** | 加 `item_view_daily(item_id, day, views)` — **只存每日聚合**，無 user／IP／query；熱門榜由佢派生；「IP 人氣榜」改成「按 IP 聚合商品瀏覽量」而唔係查詢量 | ✅ 符合（聚合、非個人） | 高 | 加 1 張表；要每日 flush 計數 |
| B | 連 item 級都唔記，熱門榜改用外部訊號（拍賣成交量、SNS 提及數） | ✅ 最嚴 | 中 | 要爬多幾個源；榜會延遲 |
| C | 記 per-click 日誌 | ❌ 直接違反 | 高 | **唔建議** |

> 「最近搜尋關鍵詞」→ **只存 `localStorage`，完全唔上傳**就冇問題（代價：換裝置就冇）。呢個可以直接做。

**要你決定：A 定 B。** 決定咗我先改 schema（加表）＋生成分類樹。

## 二、法律風險級：「避坑情報板」

### 涉及功能
- 防騙台：邊款景品容易被店家改機、做防甩片
- 夾機台難度評級：易／中／難／**詐騙台**

### 問題
1. **指名店舖／機台「詐騙」** → 日本刑法 230 條（名譽毀損）、230 條之 2（信用毀損）風險。
   即使內容係事實，舉證責任同訴訟成本都唔係小網站頂得住。而且「改機」指控極難客觀證明。
2. 平台如果唔係單純轉載而係「編輯評級」，責任更重。

### 建議改法
| 原功能 | 改成 | 理由 |
|---|---|---|
| 詐騙台評級 | **唔做**。改做「プライズ設定情報」：由廠商公開資料整理獎品數量／尺寸／有冇「はずれ」 | 對物唔對人，零風險 |
| 防騙台（邊款易被改機） | 改成「新手注意：呢類景品體積大、易被改設定」**只講貨、唔講店** | 避開名譽風險 |
| 蟹貨清單（溢價過高） | 保留，但用中性詞「流動性低／溢價高」，唔用「垃圾」；只列數據（成交價 vs 發售價比值） | 數據陳述安全 |

> 呢塊係你嘅差異點，可以做，但**必須對物不對人**。呢個唔係法律意見，落地前建議搵日本律師睇一次免責條款。

## 四、範圍膨脹：第一階段唔應該做咁多

你嘅第一階段列咗：完整分類索引 + 2 個榜 + 本地收藏 + 新貨速報。**但同時又列咗 7 個主分類（含行情數據、排行榜、收藏）同 4 種榜。**

按之前定嘅原則（先測流量、快啲上線），建議 MVP 再砍：

| 保留（第一階段） | 延後（第二階段） |
|---|---|
| 搜尋（official_name + alias） | 行情走勢圖 |
| 篩選：廠商／IP／品類／賞級／尺寸／發售月 | IP 人氣榜、廠商熱度榜 |
| 發售日程（月曆） | 避坑情報板 |
| 2 個榜：7 日熱門 + 高價保值 | 中古行情討論板 |
| 本地收藏 + 瀏覽記錄（localStorage） | 暴跌清倉榜、尾賞行情榜 |
| 新貨速報（文字） | 用戶投稿／評分 |

理由：討論板同避坑板會帶嚟審核成本＋法律風險，而且同「情報索引」核心價值無關。先證明有人查，再加。

## 五、分類樹落地方式（我建議）

**唔好手寫 JSON。** 由現有單一真相生成：

```
分類樹 = schema enum（channel_type / category / prize_tier）
       + maker 表（9 間，帶 alias）
       + ip_work 表（48 套，帶 alias）
       + brand_line 表（18 條）
       + 尺寸桶（5cm 分組）
```

即 `taxonomy.json` 由 `module1/aliases.py` + schema 生成，改一次全部同步。手寫會即刻同 DB 走樣。

**但我建議等上面第一節（熱門榜方案）同第三節（廠商清單）定咗先出**，因為：
- 主分類「排行榜」要唔要入導航，取決於方案 A/B
- 廠商清單一改，`taxonomy.json` 就要重生
