## 五、真數據生成器（模塊 #4）已開

`pipeline/export_items.py`：module2 解析 + module1 命名 → 正式 `items.json`。

| 能力 | 說明 |
|---|---|
| 輸入 | HTML corpus 目錄（按檔名分派）或 module3 dump 嘅 NamingResult JSONL |
| 政策 | **冇 `official_name` 唔入 item**，只記 `skipped`（對應 module2 政策閘） |
| 去重 | 按 `match_key(official_name)` 合併，`source_urls` 累積 |
| 誠實 | `views_7d=0`、`price=null`，`_meta` 標明 `views_available/price_available=false`，**唔造假行情** |
| 驗證 | 用 module2 fixtures 跑出 **6 款真 item**（含一番くじ 1 款），maker/ip/size/month 全對 |

切換命令：

```powershell
python prize-intel\pipeline\export_items.py                       # 生成 data/items.real.json
python prize-intel\web\demo\build_demo.py --items prize-intel\web\demo\data\items.real.json
```

（真 corpus 而家係空，所以只出 6 款；模塊 #3 一接上真抓取，同一命令即出全量。）

1. **真 corpus 未跑**：模塊 #3 fetcher 喺呢個 sandbox 無網絡，只有 fixtures 可驗。
